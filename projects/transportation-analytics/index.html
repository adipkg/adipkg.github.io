Data-Driven Transportation Analytics

This project focuses on enhancing two-wheeler safety through data-driven transportation analytics. It utilizes multi-modal data fusion and predictive modeling to provide real-time insights to riders, helping them make informed decisions and avoid accidents. A key component is the Rider Intention Prediction system that forecasts two-wheeler maneuvering patterns using multi-view video clips and motion pattern analysis.

Project Objective

To enhance two-wheeler safety through data-driven transportation analytics, utilizing multi-modal data fusion and predictive modeling to provide real-time insights to riders, with a focus on predicting rider intentions and maneuvering patterns.

Key Achievements
  • Developed a holistic multi-modal system for two-wheeler safety
  • 67% accuracy with modified ResNet model for rider intention prediction
  • Comparative analysis using confusion matrix
  • Implemented fall and skid risk detection algorithms
